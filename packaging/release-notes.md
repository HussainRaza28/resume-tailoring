Tailor tailors your LaTeX resume to a job posting. It scores the resume, rewrites only the bullets a red flag or missing keyword calls for, checks every number, name and skill against your own sources, and exports a one-page PDF. Tailor Autofill, the Chrome extension, fills job applications from a profile kept in your browser.

## Downloads

- **macOS (Apple Silicon):** `Tailor-*-arm64.dmg`. Open it and drag Tailor to Applications. The app is signed ad hoc, not notarized, so the first time, right-click Tailor and choose Open.
- **Windows:** `Tailor-Setup-*.exe`. Windows SmartScreen may warn about an unknown publisher; choose More info, then Run anyway.
- **Chrome extension:** `Tailor-Autofill-extension-*.zip`. Unzip it, open `chrome://extensions`, turn on Developer mode, press Load unpacked and choose the unzipped folder.

## Getting started

1. Open Tailor, then choose your base resume `.tex` file in Settings.
2. Pick a provider: Claude Code or ChatGPT (Codex) with your own plan, an API key for Claude or Gemini, Ollama on your computer, or the offline demo.
3. Paste a job posting and press Score.

To set up the extension from the app, press Export for Autofill in Settings, then Import from Tailor on the extension's profile page.
