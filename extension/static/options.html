Autofill

Workday ignores typing a script fakes, so Autofill types and clicks through Chrome's debugger API. While it fills a page, Chrome shows a bar saying "Tailor Autofill started debugging this browser"; it goes away when the fill ends. Nothing is read or sent.

After each Autofill, copies a report of every field it touched: label, kind of field, what was set and what the page shows, errors. Values are left out: only their lengths.
